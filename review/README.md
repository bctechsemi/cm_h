# review/ — 고객 검토 자료실

고객에게 검토를 요청하는 자료를 게시하는 공간입니다. GitHub Pages로 공개됩니다.

- 목록 페이지: https://bctechsemi.github.io/cm_h/review/
- 자료마다 폴더 하나, 개정판은 `RevA.html`, `RevB.html` … 로 추가합니다.
- 새 자료나 개정판을 올리면 `index.html`의 `DOCS` 목록 맨 위에 한 줄을 추가하고, 이전 판은 `status:'old'`로 바꿉니다.

## 주의

- **공개 저장소입니다.** 내부용(BOM 여유·발주 수량, 입고 검사, 내부 경로 등)이 들어간 파일은 올리지 않습니다. 고객검토용(`*_CustomerReview.html`)만 올립니다.
- 페이지에는 `noindex`를 넣어 검색 노출을 줄였지만, 주소를 아는 사람은 누구나 볼 수 있습니다.
