검토 · 회신 방법

  • 자료를 열어 ‘확인사항’ 탭의 확인 요청 항목을 보시고, 담당자 메일로 회신해 주시면 됩니다.
  • 항목마다 있는 Deep Dive 버튼을 누르면 그림과 함께 자세한 설명이 나옵니다.
  • 개정판이 나오면 이 목록에 새 Rev로 추가되고, 이전 판은 ‘이전 판’으로 남겨 둡니다.
  • 3D 모델 탭은 인터넷에 연결된 상태에서 보입니다. Chrome 또는 Edge를 권장합니다.
