색상 후보

화면 색은 근사치입니다. 모니터마다 달라 보이니 실제 색은 RAL 색상표 또는 도장 시편으로 확인하세요.
참고 RAL 7035는 상용 19" 블랭크 패널에도 있는 색이지만, 타공 · 스터드 가공이 필요해 세 색 모두 판금 제작 후 분체도장합니다.

색상을 고르면 3D 모델 탭에도 같은 색이 적용됩니다.

3D 모델 넥시 NX-SH1200 (22U) 장착

판넬 상단
전면 판넬 (선택 색상) EMO 가드 릴레이 MY-4SL PTFIX +24V PTFIX 0V 단자 PT 2,5 · 덕트

드래그 = 회전 · 휠/핀치 = 확대 · 우클릭 드래그 = 이동. 랙은 제품 페이지 치수(H1200 × W600 × D1000, 22U)로 그린 단순 형상이고, 판넬 장착 높이는 ‘판넬 상단’에서 바꿀 수 있습니다. 랙 안의 기존 장비 · 선반은 표시하지 않았습니다.

결선도 CHn · CH1~CH4 동일

n = 채널 번호(1~4). 라벨 n01~n24는 전선 번호(채널-번호, 예: 2-08). 적 = +24V · 회 = 0V · 청 = 신호.

동작

  • EMOn b접점이 닫힌 동안 Kn 코일 ON → 접점1 · 2 · 3 닫힘 = 정상
  • EMO를 누르거나 단선되면 Kn OFF → EMO OK = OFF, 인터록 개방
  • STOP은 b접점 — 정상 ON, 누름 · 단선 시 OFF
  • 램프는 챔버 DO가 X1(+)를 구동, X2(−)는 PDn− (0V) · LED 32 mA
  • PNP(소스) 기준. NPN이면 스위치 공통을 0V로, 램프 공통을 +24V로 바꿈 (단자 배열은 같음)

실물 확인 후 확정

  • MY-4SL 핀 번호 — 실물 인쇄로 확인 완료 (COM 9~12 · NO 5~8 · NC 1~4 · 코일 13-14)
  • 코일 정격 24VDC · 극성 13(−) / 14(+) — 확인 완료
  • KDX 탭 — a접점 1-4 · b접점 2-3 · 램프 X1(+) / X2(−) — KG오토 자료로 확인 완료
  • 접점4(12-8)와 NC 접점(1~4)은 사용하지 않음
